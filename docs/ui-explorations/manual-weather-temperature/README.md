# 手动温度弹窗 · 方向对比（第 01 轮）

## 任务
在 Dayline（Obsidian 日记插件）里记录某一刻的体感温度。用户点天气卡片上的铅笔，填一个读数和时刻，保存后覆盖自动天气。

- **用户**：写日记的人，桌面端为主，也会在手机上补记。
- **主动作**：记下一个温度与它发生的时刻。
- **组件要回答的问题**：我这一刻感觉多少度，怎么把它记下来。
- **约束**：弹窗内完成；保留时刻；支持清除；底部两个动作（保存 / 取消）。

## 三个方向

### 01 温标
- **北极星**：温度是这一刻的主角，让数字有位置感，而不是一个普通输入框。
- **生成引擎**：仪表 × 天气（温度计刻度）。
- **骨架**：日期 → 大号读数 → 温标与刻度 → 时间与动作。
- **字体**：系统无衬线；读数 68px 等宽数字，辅助 11.5–12.5px。
- **色彩**：白底；冷到暖的温标渐变 `#6f9bf0 → #e8774c`；主按钮深墨 `#1f2328`。
- **主视觉**：大号数字 + 温标轨道与滑钮。
- **控件语法**：18px 圆角卡片、9px 圆角按钮、胶囊时间块。
- **主操作手感（最终实现）**：拖滑钮调温，整度吸附；键盘输入仍可用。
- **放弃**：输入框边框、标签行、原生时间选择器。

### 02 仪表条
- **北极星**：一步到位，像调空调。
- **生成引擎**：家电面板 × 键帽。
- **骨架**：单行横条（元信息 + 减/读数/加 + 时间 + 记录）。
- **字体**：系统无衬线；读数 28px，键帽 16px。
- **色彩**：白底 + 宿主紫 `#7b3fe4`（白字 5.7:1），灰阶键帽。
- **主视觉**：中间读数与两侧键帽。
- **控件语法**：34px 方键、9px 圆角、内描边 + 底边（可按）。
- **主操作手感（最终实现）**：按住连加/连减，整度步进。
- **放弃**：大标题、温标、多余说明。

### 03 句子
- **北极星**：把读数写进日记，而不是填表。
- **生成引擎**：纸上手写 × 编辑部排版。
- **骨架**：一句话（日期时刻 + 我觉得 + 大数字 + 度）+ 元信息 + 右下动作。
- **字体**：宋体 26px 句子；数字 42px；单位「度」24px。
- **色彩**：纸 `#fbf7f1`、墨 `#2c2723`、赤陶 `#b4532a`。
- **主视觉**：句子本身，数字带荧光笔底。
- **控件语法**：无边框，只有文字动作与胶囊主按钮。
- **主操作手感（最终实现）**：点数字就地改，回车记下。
- **放弃**：所有输入框、字段标签、图标。

## 差异检验
- 骨架、字体、色彩、主视觉四项，任意两者最多共享一项：01 与 02 仅共用系统无衬线。
- 至少一个走到极端：03；至少一个打破「标签 + 输入框」品类套路：01、03。
- 不按明暗分方向：白 / 白 + 紫 / 纸 + 赤陶。
- 不撞脸：不是任何已知天气弹窗的复刻。

## 选择记录（2026-10-26）

用户选定 **01 温标**。02 仪表条、03 句子保留为后续版本的候选方向。

决定：按 01 温标实现，温标可拖、整度吸附；数字仍可直接输入。

## 推荐
**01 温标**。它把「留白」变成可用信息，数字与刻度构成主角；实现时滑钮可拖，不是装饰。
次选 **02 仪表条**：最快、最像 Obsidian 原生，适合高频补记。
**03 句子** 最像 Dayline 的品牌，但和 Obsidian 的界面语法冲突最大，更适合做「日记卡片」而不是这个工具弹窗。
