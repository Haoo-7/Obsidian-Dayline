你写过的每一天，
不该只是一串.md

Dayline 把每日笔记文件夹变成你左边看到的照片月历和右边的日记时间线，标出心情和天气。笔记原样留在你的 vault 里。

在 Obsidian 中安装在 GitHub 查看源码

三步开始

  1. 安装并启用 Dayline，运行命令 Open Dayline。
  2. 在设置里选好每日笔记文件夹，默认是 Calendar/Daily。
  3. 点日期打开那天的笔记，或者在时间线里搜过去。
