# Dayline 官网落地页 · 方向对比（第 01 轮）

## 任务

给 Dayline Journal 做一个官网落地页：简单介绍功能，让人去安装插件。本轮只做三个方向的首屏，放进对比页挑选。

## 产品事实（三个方向共用）

- **产品**：Dayline Journal，Obsidian 社区插件，v2.11.0，MIT 开源，作者 Haoo，免费、无账号。
- **它做什么**：把 vault 里一文件夹的 Markdown 每日笔记变成可视化日记。月历日期格用当天笔记里的图片当封面，标出心情颜色和天气；时间线全文搜索，按日期、心情、收藏、位置、标签、媒体筛选；去年今日；心情趋势与导出；图片 EXIF；桌面端与手机端。
- **和同类的不同**：不移动、不改写原有笔记，正文仍是 Markdown；笔记里已有的照片直接成为日历封面；免费开源、数据留在自己的 vault。
- **受众**：已在 Obsidian 写每日笔记、或想开始写日记的人。来之前，日记在文件列表里只是一串日期文件名。
- **主动作**：安装插件。正式入口 `obsidian://show-plugin?id=dayline-journal`（Obsidian 社区插件页），次要入口 GitHub `Haoo-7/Obsidian-Dayline`。
- **设备**：主视口桌面 1440×900；页面需要支持手机，但首屏对比只做桌面。
- **品牌资产**：logo（墨色环 + 日历框 + 珊瑚色镜片）`assets/dayline-logo.svg`；墨 `#0D1318`、珊瑚 `#F1694D`、纸 `#F4F6F3`；心情五色 `#ee6a54 #f0b34f #55b6c9 #4d6fb8 #7652c7`；天气图标 `icons/`。
- **示例数据**：`showcase/Dayline Demo` 的虚构日记（Northstar Cove，2026 年 7 月 1–21 日，21 天都有封面和心情）与 6 张 Unsplash 照片（来源见 `showcase/MEDIA_ATTRIBUTIONS.md`）。
- **不能伪造**：下载量、评分、用户评价、媒体报道。

## 删除清单（首屏）

| 元素 | 处理 | 理由 |
| --- | --- | --- |
| 功能列表 / 图标三列 | 删除 | 首屏只讲一件事，功能留给第二屏 |

主动作 → 结果：点「在 Obsidian 中安装」→ 唤起 Obsidian 打开 Dayline 插件页 → 用户点安装。

## 概念来源

五个全新子 Agent 按五个角度（受众处境、借一样东西、说反话、一句话加一张图、另一个领域）各出 3 个，共 15 个。删掉了重复的（底片 / 印样 / 暗房三个是同一个意思，镂空板与硫酸纸重复，去年今日出现两次）和需要大量生成图才立得住的（遗址博物馆、卡片目录、手撕日历）。选出下面三个彼此最远的。

## 三个方向

### 01 文件名 · `a.html`
- **概念**（受众处境）：文件列表里那一串日期，原地翻过来就是一面贴满照片的月历。同行替换：「vault 里的 `YYYY-MM-DD.md`」变成了「首屏的照片月历」，换成 Day One 不成立（它没有文件）。
- **北极星**：让 Obsidian 用户一眼认出自己的文件列表，再看到它变成日子。
- **标题**：你写过的每一天，不该只是一串文件名。
- **骨架**：通栏上下堆叠。上 40%：通栏两行大标题 + 一行副标题与按钮；下 60%：一条通栏画面，左端是一列文件名行，往右逐行倾倒、落位成月历照片格，画面停在转换中途，底部出血。
- **字体**：PingFang SC 600 标题 64px；正文 17px；文件名 SF Mono / Menlo 14px。
- **色彩**：底 `#F6F6F3`、墨 `#0D1318`、次级 `#5F656C`、行底 `#E8E9E5`、珊瑚 `#F1694D`（按钮和 logo 镜片）。来自 README hero 与 logo。
- **主视觉**：代码绘制的文件行 → 照片格，照片用 showcase 的 6 张图，心情色点用插件真实五色。
- **控件语法**：8px 圆角、实心珊瑚按钮，次按钮无边框文字链；与 Obsidian 文件行的 4px 圆角呼应。
- **记忆点**：文件名一行行“翻”成照片格的那一刻（选定后做成滚动驱动）。
- **放弃**：设备样机、整窗截图、渐变背景。

### 02 硫酸纸 · `b.html`
- **概念**（借一样东西）：Dayline 是覆在日记原稿上的一张硫酸纸，所有颜色和记号画在纸上，下面的原稿一个字没碰。同行替换：「原样的 Markdown 笔记」变成了「压在硫酸纸下的原稿」，换成要导入的日记 App 不成立。
- **北极星**：安静、可信：你能透过那层纸看到原文还在。
- **标题**：盖一层，不改一个字。
- **副标题**：Dayline 是一个 Obsidian 插件：在你的每日笔记上叠出一面照片月历，标出心情和天气。Markdown 正文原样不动。
- **骨架**：居中单一物件。中央一页 Markdown 原稿（白纸、等宽字），斜盖一张透明硫酸纸（不模糊，纸边从原文中间切过，纸下的字只是变浅）；纸上手绘：圈住 `mood: 2` 的珊瑚圈、日期旁一格月历 + 雨云、图片嵌入行连到当天封面照片，照片下一条 7 格“月历里的这一周”。右下角纸角卷起。标题在物件上方，按钮在物件下方。
- **字体**：Songti SC 600 标题 56px；正文 PingFang 16px；原稿 Menlo 15px；批注为 SVG 手绘线。
- **色彩**：底 `#DCE3E4`（制图台蓝灰）、原稿 `#FFFFFF`、硫酸纸 `rgba(250,252,252,.5)`、墨 `#1C2A33`（主按钮）、批注青 `#1F6F80`（由心情青 `#55b6c9` 加深）、批注珊瑚 `#ee6a54`。品牌珊瑚只出现在 logo 镜片和心情批注里。
- **主视觉**：排版本身 + 半透明硫酸纸层 + SVG 手绘批注，不用生成图；照片框和“这一周”用 showcase 图。
- **控件语法**：2px 圆角的实心墨色按钮，像制图标签；次要动作是带下划线的文字链。
- **记忆点**：硫酸纸的纸边从原文中间切过：左边是清楚的原文，右边是同一段字在纸下，只多了几笔批注。
- **放弃**：彩色大色块、照片墙、动效堆叠。

### 03 书脊 · `c.html`
- **概念**（借一样东西）：每日笔记是书架上一排只写日期的书脊，Dayline 没把书搬走，只是让每本书脊露出了那一天。同行替换：「日期文件」变成了「书脊」；订阅制日记 App 等于把书存进别人的馆藏，不成立。
- **北极星**：一整排书扑面而来，有重量、有颜色，像站在自家书架前。
- **标题**：还是那排书，每一本都认得出来。（竖排两列印在一本 196px 宽的珊瑚色书上，50px，约 500px 高）
- **副标题**：Dayline 是一个 Obsidian 插件。它读取你的每日笔记文件夹，把每一天排进照片月历和时间线，标出心情和天气。笔记不搬家，也不改写。
- **骨架**：满版图像压字。21 本书脊对应 7 月 1–21 日，从左铺到右；每本顶端天气符号、上半截是当天封面的竖切片、中间心情色带、下半截竖印日期；7 月 18 日那本被抽出 64px，旁边挂一张签（日期、标题、心情、天气）。最右边一本加宽的珊瑚色书就是标题。隔板是纯色块，副标题和按钮在隔板下方。
- **字体**：标题 PingFang SC 800 竖排 50px；书脊日期 Menlo 12px 竖排；隔板文字 15px。
- **色彩**：底 `#16120F`（书架阴影）、木隔板 `#5B3F2C`、素书脊 `#ECE8E0`、标题书脊 `#F1694D`、字 `#F3EEE6`。颜色主要交给照片。
- **主视觉**：代码绘制的书脊，照片用 showcase 6 张图按不同位置竖切成几十条。
- **控件语法**：按钮像书签：实心奶白、0 圆角、顶部一条 4px 珊瑚色；悬停上抬 2px。
- **记忆点**：一本书被抽出一半（选定后可交互：悬停抽出看那一天）。
- **放弃**：白底、产品截图、居中排版。

## 差异检验

| | 骨架 | 字体 | 色彩 | 主视觉 | 记忆点 |
| --- | --- | --- | --- | --- | --- |
| 01 | 通栏上下堆叠 | 无衬线 + 等宽 | 近白 + 珊瑚 | 文件行 → 照片格 | 翻转那一刻 |
| 02 | 居中单一物件 | 宋体 + 等宽 | 蓝灰 + 墨 + 青批注 | 原稿 + 硫酸纸 | 纸边切过原文 |
| 03 | 满版图像压字 | 粗黑竖排 | 深木 + 照片色 | 满版书脊 | 抽出一本 |

01 与 03 字体同为无衬线，其余三项都不同。02、03 主视觉不是产品界面；以产品对象为主视觉的只有 01。三个都不用标杆的“标题 + 按钮 + 设备截图”结构。

核心交互三个方向相同（点按钮唤起 Obsidian 插件页），因为安装渠道只有一个；差异放在记忆点上。
