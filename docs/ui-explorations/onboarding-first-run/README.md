# Dayline 新手引导 · 第一轮方向探索

增量项目里的「加新功能」：引导是新的，视觉沿用 Dayline / Obsidian 现有系统。这一轮只做三种做法的首屏，不做完整流程、不做动效、不接代码。

## 共用的事实

- 2026 年 10 月，今天 29 号，星期四。
- 已索引 214 天，这个月有 9 天，29 号还没有记录。
- 天气卡：广州 27°C，体感 30°，湿度 64%（样例数据）。
- 日历本身按产品现状复刻：照片封面、心情点（左下角 10px）、多篇角标、今天描边。

## 三个方向

| | 做法 | 入口 | 用户要做的事 | 代价 |
| --- | --- | --- | --- | --- |
| A 亮起来 | 自动连接 + 就地一两句 | 侧栏顶部一行状态 | 0 步；确认或更换目录 | 全新用户看到空网格 |
| B 扉页 | 一次性弹窗 | 启用后第一次打开 | 读完一页，点「打开我的日历」 | 挡在产品前面；手机上更重 |
| C 索引卡 | 常驻三行清单 | 侧栏顶部一张卡 | 逐项完成 3 件事 | 占侧栏；像作业 |

A 与 C 的差别不在视觉，而在「要不要占位」；B 是唯一打断产品的做法。日历在三张图里保持同一份数据，就是为了让差别只落在引导上。

## 推荐

A 做底，B 压成一张可跳过的欢迎卡，C 的三行清单并入 A 的空状态。理由：主流用户已经带着几百篇日记来，最有力的时刻是「格子被自己的照片填满」，向导会把它推迟。

## 保留的默认做法提示

- 「+1」角标 1.08:1：沿用产品现有样式（白字 + 阴影压在照片上），正文不在角标上。
- 大量 11–12px 标签：与插件现有界面字号一致，不是落地页正文。
- 只做了浅色主题；暗色和手机端等方向选定后再补。

## 还没做

完整流程、跳过与重看、版本标记、动效、真实实现与验证。

## 聚光灯引导（第一版原型）

`explore/spotlight.html`：按「高亮一块、其余压暗、点下一步移动高亮」做的可点原型。

- 三步：整月格子 → 有照片的一天（8 号）→ 今天（29 号）。
- 高亮是抠出来的洞，四周用 55% 黑遮罩；洞有 1px 白描边，移动时长 280ms。
- 说明卡放在视图右侧的暗区，不压住被高亮的格子；一条 1px 引线连到目标。
- 跳过、上一步、下一步、Esc、左右方向键；最后一步是「写今天」。
- 结束后遮罩消失，「已连接 Calendar/Daily · 找到 214 天」那一行留着，今天格子闪两下。
- 页面右下角「重播引导」只在结束后出现，是原型自己的控件。

窄窗口（右侧放不下卡片）时退回到卡片贴在高亮区下方；手机端还没做，应该是底部抽屉。

### 还没定

- 空库（没有旧日记）时的引导文案和步骤。
- 遮罩范围：整个 Obsidian 窗口，还是只压暗 Dayline 视图。
- 首次出现的条件（全新安装 / 从旧版升级）和重看入口。

## 聚光灯引导 · 六步版（当前原型）

窗口改成完整的 Obsidian：左侧 ribbon、Dayline 侧栏、右侧今天的笔记。按顺序：

1. **月历**：整月格子高亮，说明「写过的日子会亮起来」。
2. **一天**：高亮 25 号（有照片 + 多篇角标），讲照片、左下角心情点、右下角 +1。
3. **天气卡**：高亮侧栏顶部天气卡，说明天气默认关闭、坐标和时区在设置里。
4. **日记时间线**：高亮 ribbon 上的 Dayline 图标，讲搜索和筛选。
5. **设置**：高亮 ribbon 底部的齿轮，指向 设置 → Dayline（目录、语言、天气、EXIF 隐私）。
6. **今天**：高亮 29 号，按钮是「写今天」；点下后遮罩消失，跳到右侧今天的笔记并等待输入。

规则：
- 遮罩覆盖整个窗口（用户选定的方案），高亮区内可点，其余区域被遮罩挡住。
- 卡片默认放在被压暗的区域，用 1px 引线连到目标；只有目标上方和下方都有空间时（如 25 号、29 号）才贴在目标下方。
- 跳过随时可点，Esc 同效；左右方向键切换步骤。
- 结束后今天格子闪两下，状态行「已连接 Calendar/Daily · 找到 214 天」保留。

还没定：空库时的文案与步骤（可能只有「目录 → 今天」两步）、手机端的底部抽屉形态、设置页内部的第二层高亮（现在是跳到设置入口）。


## 九步版（当前原型）

`explore/spotlight.html`，可用 `?step=1..9` 直达任一步。

1. 月历：整月格子。
2. 一天：25 号，照片 / 心情点 / +1。
3. 心情：打开今天的心情选择器，五个颜色 + 备注。
4. 天气卡：可选，默认关闭。
5. 时间线入口：ribbon 上的 Dayline 图标；下一步打开时间线。
6. 时间线列表：按天倒序，星期和日期、标题摘要、封面。
7. 时间线搜索：全文搜索。
8. 设置：打开设置弹窗，停在 Dayline 页，讲目录 / 语言 / 天气 / EXIF 隐私。
9. 今天：按钮「写今天」，走完跳到右侧今天的笔记并留下光标；时间线留在右侧不关。

已按反馈去掉筛选面板那一步。已知问题：时间线面板在遮罩之上，第 8、9 步它不会被压暗。手机端与暗色未做。
