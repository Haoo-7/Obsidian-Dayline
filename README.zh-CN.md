# Dayline Journal

中文说明现在是默认的 [README.md](README.md)。English documentation lives in [README.en.md](README.en.md).

隐私说明：天气设置里的 `使用当前位置` 按钮只在你主动点击时读取一次设备定位并填入坐标（保留 2 位小数，约 1 km 精度），不会自动跟踪；该按钮仅在 Obsidian 手机端显示。天气数据发送到 [Open-Meteo](https://open-meteo.com/)，可选的 GPS 地名解析发送到 OpenStreetMap Nominatim（默认关闭）。详见 [README.md](README.md)。
