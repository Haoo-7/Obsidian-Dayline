# Dayline public showcase

This folder is a self-contained, synthetic journal used for the public Dayline screenshots and README examples.

It intentionally contains no private notes, personal locations, EXIF data, downloaded personal media, or real schedules. The journal entries use the fictional place name `Northstar Cove` and dates from July 1 through July 21, 2026.

The calendar has 21 recorded dates: every cell from July 1 through July 21 has an image cover and a mood marker. July 22 onward is intentionally empty, so the public showcase does not look like a set of future diary entries.

## Use it in an Obsidian sandbox

1. Copy `Dayline Demo/` into the vault root.
2. In Dayline settings, set **Daily notes folder** to `Dayline Demo/Daily`.
3. Set the display language to English for the reference screenshots.
4. Open the calendar and journal timeline commands, then open any July note for the reference view.

Weather is optional. The reference screenshot uses synthetic coordinates and a fictional display label so the weather card can be shown without exposing a real location. The core showcase works with weather disabled.

The sample exercises the public-facing paths for:

- month navigation, active-date states, a continuous 21/21 image-cover run, mood dots, weather badges, and multiple entries on one date;
- timeline full-text search, date range, mood, favorite, location, tag, and media filters;
- image, video, audio, cover, and mood entries;
- opening a daily note from a calendar cell or timeline card.

The media files are intentionally small and normalized to PNG/WAV/MP4 formats for predictable local rendering.
